# Como publicar o site na Vercel

## Opção 1 – Arrastar e soltar (mais fácil)

1. Acesse https://vercel.com e faça login (pode usar conta do Google ou GitHub).
2. Clique em **Add New… → Project**.
3. Escolha **Upload** (ou “Deploy without Git”).
4. Arraste a pasta **chai_site_updated** inteira.
5. Clique em Deploy.
6. Pronto! Você receberá um endereço tipo `https://algo.vercel.app`.

## Opção 2 – Com GitHub (recomendado para atualizações futuras)

1. Crie uma conta no GitHub (se não tiver).
2. Crie um repositório novo (ex: `chaianjos-site`).
3. Suba todos os arquivos desta pasta para o repositório.
4. No Vercel, clique em **Add New… → Project** e importe o repositório do GitHub.
5. Toda vez que você alterar o código no GitHub, a Vercel atualiza o site automaticamente.

## Depois de publicar

1. Anote o endereço que a Vercel gerou (ex: `https://chaianjos.vercel.app`).
2. Quando registrar o domínio próprio no Registro.br, volte aqui e me avise.
3. No painel da Vercel → Settings → Domains → adicione o domínio.
4. A Vercel vai mostrar os registros DNS que você precisa colocar no Registro.br.

## Arquivos importantes

- `index.html` → página inicial
- `adocao.html` → página de adoção (SEO)
- `doacoes.html` → página de doações (SEO)
- `transparencia.html` → prestação de contas
- `privacidade.html` → política de privacidade
- `styles.css` → estilos compartilhados
- `img/` → fotos dos animais
- `logo-chai.jpg` → logo
